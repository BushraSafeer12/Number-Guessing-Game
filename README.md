# Number-Guessing-Game
A simple and fun Number Guessing Game built with Python.
The computer randomly selects a number, and the player has to guess it.

🎮 How to Play
Run the GuessingGame.py file.
Enter your guess when asked.
The game will tell you if your guess is:
📈 Too high
📉 Too low
🎉 Correct
Keep guessing until you find the correct number!
✨ Features
Random number generation
User input
Helpful hints
Simple and interactive gameplay
Beginner-friendly Python project
